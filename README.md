# Inas Gedichte-Abenteuer 🌟

Eine interaktive, deutschsprachige Lern-Web-App zur Vorbereitung auf den Gedichte-Test (Klasse 5, Gymnasium).

## Features

- **10 Lernbereiche**: Grundlagen, Reimschema, Metrum, Sprachliche Bilder, Vergleich, Personifikation, Metapher, Gemischt, Prüfungstraining, Abschlussprüfung
- **6 Progression-Levels**: Verstehen → Erkennen → Anwenden → Erklären → Selbst machen → Mini-Test
- **Vielfältige Übungstypen**: Multiple Choice, Wahr/Falsch, Lückentext, Silben-Klick (Metrum), Reimschema-Zuordnung, Wörter markieren, Zuordnen, Freitext mit Selbstcheck
- **Gamification**: Wissensterne, Streak-Tracker, 8 Abzeichen
- **Adaptive Wiederholung**: Schwache Themen werden automatisch vorgeschlagen
- **Satzstarter**: Formulierungshilfen für die Klassenarbeit
- **Gedichte-Bibliothek**: Übersicht aller Übungsgedichte
- **Eltern-Modus**: Fortschrittsübersicht auf einen Blick
- **Offline-fähig**: Einzelne HTML-Datei, keine Internetverbindung nötig
- **Responsive**: Funktioniert auf Handy, Tablet und PC

## Technologie

- Vanilla HTML/CSS/JavaScript
- Keine externen Abhängigkeiten
- localStorage für Fortschrittsspeicherung

## Nutzung

Einfach `index.html` im Browser öffnen – fertig!
